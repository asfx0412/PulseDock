# PulseDock 6.16.0 发布说明

发布日期：待 GitHub Release 发布时确认。

## 本版重点

- **Clash 订阅可自动更新**：在设置中明确启用后，PulseDock 会按用户选择的 15–240 分钟间隔，请求已验证的本机 Mihomo/Clash 控制器刷新订阅 provider，再重新读取本地额度。未启用时只读取本机数据，不会自行刷新订阅。
- **社区额度重置信号提醒**：可根据第三方公开信号的可信度与未来时间窗口，发送首次发现、计划变更、重置前 60/30 分钟及完成确认提醒。飞书外发仅保留这一类社区额度提醒；设备、SSH、网络、温度和普通额度事件不会发送到飞书。
- **设备较多时更易使用**：远程设备页增加名称/SSH 别名、健康状态与网络范围筛选；详情按需展开，SSH 探测使用最多三槽的优先队列，手动刷新优先处理。

## 凭据保险库与 Touch ID

- 默认可选择“Touch ID 新保险库（不读取旧登录钥匙串）”。解锁时先请求 Touch ID，不会读取、迁移或删除旧登录钥匙串，因此不会触发旧项的密码框。
- 首次用 Touch ID 建立新保险库后，请重新填写并保存需要的 Clash、飞书和 API 凭据。旧凭据仍保留在原钥匙串中，但不会自动导入。
- 没有可用 Touch ID、未录入或被系统锁定时，macOS 会使用本机登录密码完成系统认证；主动取消 Touch ID 不会自动跳转为密码输入。
- 修复 ad-hoc 签名版本首次建立保险库时的 `OSStatus -34018`。现在先完成 Touch ID 验证，再写入本机钥匙串，避免依赖未配置的 Apple Team Keychain access-group。

## 可靠性修复

- Clash Profile 原子替换、多目录发现、控制器不可达或暂时不可读时保留最后一次成功额度，避免将有效值清空。
- 社区信号上游响应畸形时保留已有快照；限制响应体、单飞请求、HTTPS 来源链接和最小缓存。上游未提供生成时间时明确标注，不将本机读取时间误显示为上游时间。

## 安装与升级

1. 完全退出运行中的旧版 PulseDock。
2. 解压 `PulseDock-6.16.0.zip`，以新的 `PulseDock.app` 替换测试副本或应用程序中的旧 App。
3. 启动后确认窗口标题版本为 `v6.16.0`。
4. 若启用 Touch ID 新保险库，点击“解锁凭据”，完成指纹验证后重新填写并保存所需密钥。

本版本仍为本地人工验收后的待发布版本。GitHub Release 由 GitHub Actions 重新构建 ZIP、签名更新清单并发布；不要上传本地生成的 manifest 或任何私钥。
