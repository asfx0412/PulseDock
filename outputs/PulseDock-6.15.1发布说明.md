# PulseDock 6.15.1 发布说明

发布日期：2026-09-04

## 新功能

- 新增 GitHub Copilot 个人用量连接器：可配置多个 GitHub 用户名与 Fine-grained `Plan: read` PAT，并仅显示 GitHub 官方接口实际返回的 AI Credits、Premium Requests 及 SKU/模型明细；不会猜测套餐总额、组织用量或剩余百分比。
- 新增外观与主题设置：大/小窗口可跟随或分别使用本地背景图，支持填充/适应/居中、暗化、背景层磨砂、卡片透明度与边框，以及原创 Win97 复古主题。导入图片会校验格式、尺寸与像素，去除 EXIF/GPS 后仅保存到 PulseDock 专属目录。

## 修复：完整且稳定的天气地点

- 修复天气地点只能保持“深圳市”等城市级名称的问题。自动定位重新解析出同一城市的区/县、省/州、国家时，即使没有移动超过 2 km，也会将旧地点升级为完整行政层级。
- 防止地址信息倒退：已经确认的“南山区 · 深圳市 · 广东省 · 中国”等完整地点，不会被之后只含“深圳市”的粗略系统定位结果覆盖。
- 原有防抖仍适用于真实地点变更：跨区/跨城更新仍要求新鲜、足够准确的位置以及约 2 km 的位移阈值，避免 Wi‑Fi 定位漂移跳城。

## 测试状态

- 离线确定性测试已覆盖“城市级升级到区县级”与“区县级不被城市级降级”，并已通过。
- Release 构建门禁会执行完整离线测试、arm64 构建、ad-hoc 签名、ZIP 解包校验，并生成由客户端公钥验证的更新清单。

## 发布后人工验证

在真实 Mac 的自动跟随位置模式中，点击“立即检查”：若 macOS 反向地理编码提供区/县，应从当前城市级名称升级为完整地点；若系统只提供城市级，应用会诚实保留城市级，不能臆造区域名称。
