# PulseDock 6.14.0 发布说明

发布日期：2026-09-01

## 新功能

- Codex、天气与 API 额度读取采用统一恢复状态。已有数据时，短暂失败会保留最后成功值，并在 30 秒、2 分钟、10 分钟后自动重试。
- 工作台失败提示改为低干扰图标：点击可查看安全的失败原因、上次成功时间、下次自动重试和“立即重试”；连续失败三次才升级提示。
- Cursor 设置页显示 Auto 与指定模型两项明细；工作台只显示综合剩余百分比。
- 自动更新强化为签名发布说明、严格 GitHub Release 地址、SHA-256、Bundle ID、版本、arm64 与代码签名校验；新 App 必须启动确认，否则恢复旧 App。

## 修复

- 修复新版 Codex app-server 慢启动时固定等待两秒后过早发送请求、导致额度长期显示 `--` 的问题。现在确认 `initialize` 成功后才读取额度，初始化最多等待 12 秒。
- 修复天气、Codex 与 API 的一次 DNS/TLS/HTTP/解析波动清空工作台旧值、需要用户手动刷新的问题。

## 已验证

- 确定性测试与 arm64 Release 构建、临时签名、ZIP 解包签名校验通过。
- ZIP SHA-256：`c526a32298ae6d52c9fc4cd380381ad96db87d2eac66938e92f35f83bd920788`

## 私有内测与自动更新状态

本 Release 仅用于私有内测。由于 GitHub 私有仓库的 Release 下载需要登录权限，普通已安装 App 不带 GitHub Token，因此自动更新的真实在线升级/回滚验证待仓库公开发布或改用专用测试分发源后完成。

GitHub Actions 会使用 `PULSEDOCK_UPDATE_PRIVATE_KEY_BASE64` 生成并使用客户端内置公钥反验更新清单；这只证明签名发布链，不代表私有仓库中的普通 App 已可自动下载更新。本版不宣称自动更新已正式可用。
