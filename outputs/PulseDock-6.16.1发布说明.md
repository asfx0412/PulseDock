# PulseDock 6.16.1 发布说明

发布日期：2026-09-13

## 重点修复：Touch ID 凭据保险库

- Touch ID 保险库升级为独立的 `credential-vault-v3`。选择 Touch ID 后，PulseDock 不会读取、迁移、删除或回退到旧的 v1/v2 登录钥匙串项。
- Touch ID 成功后，随后的钥匙串读取明确禁止系统再展示认证窗口；因此旧钥匙串 ACL 异常会显示为可见失败，而不会再出现第二个“登录”钥匙串密码框。
- 在未使用 Apple Developer Team 签名的本地发布方式下，v3 使用已验证可写的普通本机钥匙串项；Touch ID 由读取前的系统认证门禁负责。它不再尝试会导致 `OSStatus -34018` 的 `.userPresence` 项，也不使用当前 macOS 无法写入的旧式 Keychain ACL。
- 无 Touch ID、未录入指纹或指纹被系统锁定时，才由 macOS 提供系统密码回退。取消指纹认证不会静默切换成密码。
- 老用户的旧登录钥匙串仍原样保留，不会被新版本自动访问；首次使用 v3 后请在解锁状态下保存一次需要的连接器/飞书/Clash 凭据。

## 更新体验

- 自动更新发现新版时改为展示最多三条面向用户的变更摘要，并提供“查看完整更新”直达已验证的 GitHub Release 页面。
- 下载、Ed25519 清单验签、SHA-256 校验、替换和重启流程不变；完整说明仍由签名清单覆盖。

## 本版本继续保留的功能

- Clash 订阅配置自动更新仍是显式启用、按 15/30/60 分钟节流的本机 Mihomo provider 更新；单纯额度读取不会触发 PUT 更新。
- 飞书外发仍只用于用户启用且已验证的社区额度重置信号，不会自动发送设备、SSH、网络或一般额度事件。

## 升级注意

本地 ad-hoc 签名的 App 首次启动可能仍由 Gatekeeper 询问是否打开，这与保险库解锁无关。请在“设置 → 凭据保险库”中选择 Touch ID，并完成一次“解锁 → 保存 → 锁定 → 再次解锁”验证；成功后不应出现登录钥匙串密码框。
