# PulseDock 6.16.3 发布说明

发布日期：2026-09-15

## 本次重点修复

- 凭据保险库收敛为唯一的 Touch ID v4 实现。Touch ID 解锁后不会读取、迁移、删除或回退到 v1/v2/v3 历史登录钥匙串项。
- 移除“仅登录钥匙串密码”解锁模式、旧凭据导入入口及相关代码，杜绝旧项再次触发 macOS 登录密码框。
- Touch ID 流程只使用生物认证；取消、失败、未录入或锁定时仅显示失败状态，不会自动退回 macOS 登录密码。
- v4 的读取、首次创建、更新与清除都禁止 Keychain 认证 UI。首次 Touch ID 成功只解锁本次会话，填写并保存真实凭据时才创建 v4 项。

## 升级说明

首次升级到 6.16.3 后，请在“设置 → 凭据保险库”点击“解锁凭据”，完成 Touch ID 后重新填写并保存当前需要的 Clash、飞书和额度连接器凭据。旧钥匙串项不会自动读取，保留在系统中以便用户自行确认后清理。

## 已包含的 6.16 系列能力

- 可选的 Clash Provider 定时同步与本地额度重读。
- 社区额度重置信号的本地/飞书提醒（仅社区事件）。
- 远程设备搜索、筛选与最多三槽的优先探测队列。
